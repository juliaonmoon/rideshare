# Settings benchmark (2026-10-19)
Sources were thin (web search only; verify in each app before quoting).
- BlaBlaCar: ride-style on the profile (chattiness "Bla / BlaBla / BlaBlaBla"; smoking, pets, music), shown as icons on trips. -> We have chat style + pets tags.
- Uber: "Women Preferences" is a preference, not a guarantee, with a possible longer wait; drivers opt in too. Lyft: Women+ Connect. -> Deliberately NOT built: needs gender data, verification and a legal review (BC Human Rights Code). Candidate for later.
- Matching research/illustrative designs filter on a detour limit (minutes and %) and rate drivers; we already filter on the driver's max detour/wait.
Where we aim to be better: per-trip override of defaults, auto-accept with a seat cap and points check, driver sets detour AND wait, one account can be driver and rider with separate settings.
Not yet built: notification settings (need push), min price, % detour cap, verified-only requests, women-only matching.
