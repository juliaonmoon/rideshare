# Expanding Beyond Metro Vancouver (e.g. BC → USA / California)

_2026-10-06. Search summaries only. **Not legal advice.**_

## Short answer

Technically possible, but it is a **different product** with a different legal footing. Do not design for it on day one.

## Daily commute vs long-distance

| | Daily commute (our core) | Long-distance / cross-border |
|---|---|---|
| Trip | Same route, every weekday | One-off, hours or days |
| BC carpool exemption | Fits cleanly (one return trip, home ↔ work) | Does **not** obviously fit; the exemption is written around commuting to work or a common destination |
| Matching | Detour and time windows | Date, seats, luggage, stops |
| Existing apps | TransLink/Liftango, gobyRIDE | [Poparide](https://www.poparide.com/en-ca/), [Carpooll](https://carpooll.com/), Ridesharing.com, Seat Sherpa (California/Nevada) |

## Cross-border issues to resolve

1. **Law in every state is different.** In California, regulators have treated app-based carpooling with individual fares as unlicensed charter-party service; a [carve-out exists](https://leginfo.legislature.ca.gov/faces/billTextClient.xhtml?bill_id=201520160AB1360) for certain TNC shared rides, and it is unclear whether our model qualifies.
2. **Cabotage-style limits.** Per [commercial-carrier guidance](https://borderpro.ai/blog/2026-03-31-cabotage-rules-us-canada), Canadian-based drivers may carry passengers from Canada into the US, but not pick up and drop off passengers within the US. Whether this applies to non-commercial cost-sharing needs a lawyer.
3. **Insurance.** [ICBC basic coverage extends to the US](https://icbc.com/insurance/products-coverage/basic-insurance), but liability limits can be exhausted quickly by US medical costs, and basic damage cover does not apply outside BC. Longer trips raise the stakes.
4. **Border.** Ridesharing platforms in this space require all travellers to be 18+, have no criminal record in either country and carry passports. A driver crossing with strangers carries risk if one passenger is refused entry.
5. **Cost cap still applies.** Contributions must stay within the trip's real operating cost, so over 1,500 km the numbers are large and the "no profit" line must stay clear.

## Competitors for long-distance

- [Poparide](https://www.poparide.com/blog/looking-for-blablacar-usa/): 2M+ members claimed, Canada-wide, US only in Texas.
- BlaBlaCar has [never operated in the US](https://seatsherpa.app/guides/blablacar-usa).
- Seat Sherpa operates in California and Nevada today (per search result).
- Ridesharing.com positions itself as a Canada–US option.

## Recommended path

1. **Phase 1:** BC daily commutes (Burnaby/Metro Vancouver).
2. **Phase 2:** other BC regions, still commute-based (Victoria, Kelowna, Fraser Valley).
3. **Phase 3 (optional):** long-distance within BC/Canada, **then** Washington State as the first cross-border step.
4. **California last.** Get a lawyer in each jurisdiction before launching there.

Designing the points system and pricing so that the cost cap works at any distance is cheap to do now. Building US-specific features is not.
