# RideShare (working name)

A **driver-centred commuter carpool app** for people who drive to work every day.
Riders chip in for gas **or** pay with **points** earned by driving others.
No profit for drivers — the goal is to **lower the cost of driving**, with zero extra effort.

> Status: planning. Nothing is built yet. Drafted 2026-10-05.

## One-page summary

| | |
|---|---|
| **Who** | Daily commuters who drive (starting point: Burnaby / Metro Vancouver) |
| **Problem** | Driving to work is expensive; most cars carry one person |
| **Idea** | Driver enters destination → app suggests riders already near the route → one tap to accept |
| **Payment** | Rider chooses: **cash share of gas** or **points** (earned when they drive someone else) |
| **Fairness** | Cost is split across everyone in the car, so more riders = cheaper per person |
| **Driver rule** | Driver sets max detour + max wait. App only shows riders inside those limits |
| **Maps** | Google Maps (or Mapbox) for routes, ETAs, pickup points |

## Verdict (short)

- **Is there room?** Narrow. BC already has a free TransLink-backed commuter app (Liftango) and gobyRIDE (cost-share + points). Consumer carpool apps have a poor track record (Waze Carpool shut down 2022); survivors sell to **employers**.
- **Your differentiators:** driver-first detour control, and a points system that makes the app two-sided *without needing cash*.
- **Biggest risks:** (1) not enough users on the same routes at the same time, (2) BC law/insurance only allows **cost-sharing**, not profit, (3) points must be designed so they can't be turned into cash.
- **Recommendation:** first try the existing BC apps and find the real gaps; talk to TransLink/Liftango; only then pilot (one Burnaby employer or campus) and build.
- **Money:** drivers can never profit (law/insurance). Platform can run **non-profit / cost-recovery**.
